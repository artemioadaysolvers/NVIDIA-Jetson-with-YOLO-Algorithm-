Software desarrollado para ejecutar el algoritmo YOLO en una NVIDIA Jetson, utilizando el navegador Chromium como frontend para renderizar una interfaz desarrollada en HTML y JavaScript, y visualizar imágenes en tiempo real procesadas mediante Python desde el backend.

Las herramientas para construir este sistema como el NVIDIA Jetson son utilizadas en el Laboratorio de la Universidad Adolfo Ibáñez de Viña del Mar por el
Profesor Cedric Little.

El código fue generado el Ayudante Instructor Artemio Araya con ayuda de Codex.
